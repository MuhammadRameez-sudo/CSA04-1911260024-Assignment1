=== Task 12: Day-4 Design Challenge — Edge + Cloud Hybrid Architecture Evaluation ===
1. Home Monitoring Device (Edge RTOS: Zephyr/FreeRTOS + Hardware TrustZone):
   - Local anomaly detection & buzzer alarm : 1.8 ms (< 10 ms hard deadline met locally!)
   - WAN Internet telemetry upload (MQTT/TLS): 45.0 - 250.0 ms (store-and-forward buffer on disconnect)
2. Cloud Shared Records Service (Distributed Kubernetes + CockroachDB/Spanner Raft Consensus):
   - 3-Hospital + Home Portal Read Latency  : 14.2 ms (regional edge cache + mTLS OAuth2/SMART-on-FHIR)
   - Availability (Multi-AZ 3-way quorum)   : 99.999% (survives entire availability zone failure)
3. Decision: MODIFY Original Architecture -> Retain Hard-RTOS at Edge, Evolve DB to Hybrid Cloud-Edge.
